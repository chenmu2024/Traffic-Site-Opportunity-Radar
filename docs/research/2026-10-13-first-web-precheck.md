- 初筛：属于真实在线工具，但竞争已存在；自然流量、非品牌份额、广告收益和流量国家均未知。
- **第一优先需要的数据：** Semrush Organic Research，国家 Brazil，域名 pix-qr-code.com，截图或导出 Pages 和 Positions，并保留日期、工具 URL、自然流量估计、非品牌关键词。

- 风险：此前通用 Pix QR 码词已知有较高 KD，不重复论证整个 QR 码市场，仅调查 Placa Pix 是否为独立的、可进入的工具需求。

- 仅在后续发现真实排名证据后可查：svg to vector drawable / svg to android xml converter / svg to vector drawable online / android vector drawable converter。

## 研究纪律

1. GitHub Stars、论坛引用、上线时间和是否索引，均不能证明每月1万—10万自然搜索流量。
2. 国家、日期、工具 URL、搜索意图和 Semrush 来源缺失时，不输出 Volume、KD 或收入估计。
3. 不将同义词搜索量简单相加；不未经用户批准而创建网站或新增内页。
4. 先核实一个最有可能的独立在线工具竞争对手，失败再更换，控制查询成本。
