## A. pix-qr-code.com · 巴西葡语

- 网站：https://pix-qr-code.com/
- 已确认的在线工具：Pix 收款二维码和 Placa Pix 个性化收款牌。
- 工具使用说明：https://www.pix-qr-code.com/blog/como-gerar-uma-placa-personalizada-para-sua-chave-pix
- 独立公开介绍：https://www.tabnews.com.br/itsfematheus/pitch-criei-um-gerador-de-qr-code-e-placas-personalizadas-para-pix
- 已存在的其他独立工具：https://geradorplacapix.com.br/ 、https://pixnamao.com.br/ 、https://www.devthru.com/tools/finance/placa-pix
- 初筛：属于真实在线工具，但竞争已存在；自然流量、非品牌份额、广告收益和流量国家均未知。
- **第一优先需要的数据：** Semrush Organic Research，国家 Brazil，域名 pix-qr-code.com，截图或导出 Pages 和 Positions，并保留日期、工具 URL、自然流量估计、非品牌关键词。
- 后续精确待查关键词（BR 葡语；尚无真实 Volume/KD/CPC）：gerador de placa pix / placa pix personalizada / placa pix para imprimir / placa pix com qr code / qr code pix com logo。
- 风险：此前通用 Pix QR 码词已知有较高 KD，不重复论证整个 QR 码市场，仅调查 Placa Pix 是否为独立的、可进入的工具需求。

## B. svg2vector.com · 英文开发工具

- 网站：https://svg2vector.com/
- 在线转换：SVG 等素材变为 Android VectorDrawable XML，网站说明浏览器内转换。
- **商业模式注意：网站当前显示订阅或一天访问权收费，不能把它算作 AdSense 赚钱案例。**
- 技术出处：https://github.com/a-student/SvgToVectorDrawableConverter.Web
- 独立定性使用线索：https://stackoverflow.com/questions/55433070/converting-svg-to-android-vector-drawable
- 已有免费竞品：https://svg2vector.app/ 、https://svgcode.com/svg-to-android
- 初筛：技术需求存在公开讨论，但真实非品牌 SEO 和月搜索量未知，且英文市场有直接竞争，暂不优先消耗 Semrush 查询次数。
- 仅在后续发现真实排名证据后可查：svg to vector drawable / svg to android xml converter / svg to vector drawable online / android vector drawable converter。

## 研究纪律

1. GitHub Stars、论坛引用、上线时间和是否索引，均不能证明每月1万—10万自然搜索流量。
2. 国家、日期、工具 URL、搜索意图和 Semrush 来源缺失时，不输出 Volume、KD 或收入估计。
3. 不将同义词搜索量简单相加；不未经用户批准而创建网站或新增内页。
4. 先核实一个最有可能的独立在线工具竞争对手，失败再更换，控制查询成本。
