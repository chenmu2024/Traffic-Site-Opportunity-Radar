# New independent SEO traffic site research · 2026-10-13

## Scope and evidence

This note is NOT a Semrush volume report or evidence of achieved Google organic traffic. Public indexed pages were inspected and show specific functional tools. No SaaS MRR, revenue or existing user's production site is involved. All ranking, Volume, KD, CPC, DR and income values remain unknown.

## Priority 1: Brazil · printable label maker

- Exact core keyword to check only first: **gerador de etiquetas para imprimir** (BR Keyword Overview; Volume and KD).
- Verified competing public functionality:
  - https://msdicas.com.br/ferramentas/etiquetas/ — barcodes, Brazilian Pimaco A4 sheet templates and PDF printing.
  - https://openlabelmaker.com/pt/ — draggable browser labels, printer formats, QR/barcodes, PDF output.
  - https://utilsworld.com/pt/labelpdf/ — client-side printable label-sheet PDF.
- Advantage hypothesis: free client-side label layout for Brazilian household and microretail, Pimaco formats, multirow CSV, barcode + QR, precise mm scaling. Feature differentiation is not proven against existing competitors.
- Risks: established competitors and branded/retailer intent; generic 'etiquetas para imprimir' or shipping label searches must NOT substitute for standalone tool use.
- Supporting phrases for later ONLY IF core Volume/KD passes: gerador de etiquetas online, criar etiquetas para imprimir, etiquetas para imprimir a4. Do NOT sum search volumes.

## Priority 2: Brazil · wallpaper roll calculator

- Exact core keyword: **calculadora de papel de parede** (BR Keyword Overview; Volume and KD).
- Functional competitors:
  - https://www.arqpedia.com.br/calculadora-de-papel-de-parede/ — roll and design repeat / rapport inputs.
  - https://icalculadora.com.br/calculadoras/papel-de-parede — per-wall dimensions, cuts, and exact strips per roll.
  - https://www.calculohub.com.br/calculadoras/papel-de-parede-rolos — dimensions and repeat/waste estimates.
- Advantage hypothesis: visible integer cut lengths/strips and repeat-aware buying estimate; optional retailer product pack comparison. Function is inexpensive to run but readily replicated.
- Risks: many live competitors; keyword may be low Volume, Google may prefer retailer sites; weak defensibility and limited repeat visits.
- Supporting phrases for later ONLY IF core Volume/KD passes: quantos rolos de papel de parede preciso, calcular papel de parede por m2.

## Priority 3: Mexico · printable label maker
